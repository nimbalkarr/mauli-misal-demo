
# Mauli Misal & Snacks

A restaurant website demo concept for Mauli Misal & Snacks, located in Katewadi, Baramati, Maharashtra.

## Features

- Restaurant homepage with a hero section
- Food menu with images and sample prices
- About the restaurant section
- Location and directions
- Contact and WhatsApp buttons
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Demo Notice

This is an unofficial demo concept created for presentation purposes. Menu items, prices, opening hours, and contact details should be confirmed with the restaurant owner.
